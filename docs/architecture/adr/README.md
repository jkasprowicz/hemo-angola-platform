# ADR Index

This directory provides a lightweight ADR baseline aligned with the current repository and the historical v1.0 specification.

- `ADR-001`: PostgreSQL as the central relational store
- `ADR-002`: local-first collection with later synchronization
- `ADR-003`: Django/DRF backend
- `ADR-004`: React PWA frontend
- `ADR-005`: IndexedDB browser persistence
- `ADR-006`: session authentication
- `ADR-007`: configurable indicator catalog
- `ADR-008`: idempotent synchronization

These ADRs are concise by design and are meant to anchor the documentation and traceability matrix created in this sprint.
