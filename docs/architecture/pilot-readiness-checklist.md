# Pilot Readiness Checklist

This checklist is a repository-side companion to the historical v1.0 readiness gates.

## Gate 1: Domain

- Minimum indicator set approved
- Roles and review workflow validated with INS
- Pilot unit and reporting policy defined

## Gate 2: Product

- Collection, validation, close and sync flow demonstrated
- Dashboard scope for pilot agreed
- Conflict policy decided

## Gate 3: Infrastructure

- Production environment provisioned
- HTTPS validated
- Backup and restore drill executed

## Gate 4: Operation

- Users created
- Local responsible person identified
- Support and escalation path agreed

## Gate 5: Go-live

- Joint readiness approval recorded
- Pilot start window agreed
